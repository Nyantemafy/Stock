==================================================
PROCESS - Changements techniques effectués
==================================================

1. Résumé de l’aléa

L’aléa demande de faire plusieurs saisies d’entrée ou de sortie de stock, puis de tout valider en une seule fois.

2. FormGenerator.java

Le service généralisé FormGenerator a été étendu pour gérer plusieurs lignes de formulaire.

Méthodes ajoutées :
- genererFormulaires : crée un panel avec plusieurs formulaires du même type.
- ajouterFormulaire : ajoute une nouvelle ligne.
- supprimerDernierFormulaire : supprime la dernière ligne.
- getFormulaires : récupère toutes les lignes saisies.
- estVide : permet d’ignorer une ligne totalement vide.

Ce choix permet de garder le service généralisé existant au lieu de créer un service spécifique.

3. AffichageGenerator.java

Ajout de genererScrollPane.

Cette méthode sert à afficher les lignes multiples dans une zone défilante.

4. Main.java

Les méthodes ajouterEntreeStock et ajouterSortieStock ont été modifiées.

Avant :
- une fenêtre contenait un seul formulaire ;
- une validation enregistrait une seule ligne.

Maintenant :
- la fenêtre contient plusieurs lignes ;
- les boutons "Ajouter ligne" et "Supprimer ligne" permettent de gérer les lignes ;
- une seule validation lit toutes les lignes ;
- les lignes sont transformées en List<MouvementStock>.

Méthodes ajoutées :
- creerPanelSaisiesMultiples : construit l’affichage des lignes multiples.
- lireEntreesStock : lit toutes les lignes d’entrée.
- lireSortiesStock : lit toutes les lignes de sortie.
- verifierMouvementsSaisis : vérifie qu’au moins une ligne est remplie.
- lireValeurObligatoire : vérifie les champs obligatoires.
- lireDateMouvement : convertit la date au format yyyy-MM-dd.

La fiche de l’article sélectionné est affichée dans la fenêtre pour savoir sur quel produit les lignes seront enregistrées.

5. MouvementStock.java

Ajout d’un constructeur simplifié.

Il permet de créer un MouvementStock avec seulement :
- typeMouvement ;
- nombre ;
- prixUnitaire ;
- dateMouvement ;
- idSource.

Cela sert à transporter les lignes saisies vers le DAO sans créer un nouveau modèle.

6. ArticleDao.java

Ajout de méthodes pour enregistrer plusieurs mouvements en une seule transaction.

Méthodes ajoutées :
- ajouterMouvementsStock : enregistre plusieurs entrées.
- ajouterSortiesStock : traite plusieurs sorties.

La logique existante de sortie FIFO, LIFO et CUMP a été conservée.
Elle est réutilisée dans une méthode privée avec la même logique qu’avant.

Si une ligne du lot échoue, un rollback est fait.
Donc le lot est enregistré entièrement ou pas du tout.

7. Suppression d’article

La suppression d’article a été sécurisée.

Changements :
- le message de confirmation affiche le nom de l’article ;
- les mouvements sont supprimés avant l’article ;
- la suppression se fait dans une transaction.

8. Remarque sur idSource

idSource n’est pas l’id du produit.

Le produit est l’article sélectionné dans le tableau.
Son id est idArticle.

idSource garde son rôle de source du mouvement.
